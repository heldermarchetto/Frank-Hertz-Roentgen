💾 Fortschritt speichern

Weg 1 – Datei: Klicke auf „Datei herunterladen“. Die Datei landet meistens im Ordner Downloads. Bewahre sie gut auf (z. B. in OneDrive oder auf dem USB-Stick).

Weg 2 – Code: Kopiere diesen Code und füge ihn z. B. in eine E-Mail an dich selbst oder in ein Word-Dokument ein.

📂 Fortschritt laden

Weg 1 – Datei: Wähle deine gespeicherte Datei (Endung .json) aus.

Weg 2 – Code: Füge deinen gespeicherten Code hier ein und klicke auf „Code laden“.

🗑 Alles löschen?
